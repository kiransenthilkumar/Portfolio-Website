dir - list directory
cd foldername - change directory
cd .. - back
mkdir foldername - create directory
notepad filename.txt - create folder
Directory - D:
move source destination - to move the file into folder
dir foldername or path - list specific folder

systeminfo - list system information
systeminfo | clip - to copy in the clipboard
systeminfo | findstr word - to serach a particular word

-----------------------------Network Commands-----------------------------

ipconfig , ipconfig | findstr - combination
nslookup domain_url - to find domain ip
ping domain_url - to check network , server alive? by sending packet response

netsh wlan show profiles - to display wifi details
netsh wlan show profiles "profile" key = clear - show password and others

curl ipconfig.io - to find public ip
curl wttr.in/location - to find current weather
curl qrenco.de/"text or link" - Qr code generator

-----------------------------Advanced Commands-----------------------------

copy /b imagename+zipname outputname - To zip a file within an image
attrib +h +s +r filename/folder - To hide
attrib -h -s -r filename/folder - To Unide

shutdown /f /s /t seconds - to shutdown after a time 
shutdown /f /s - immediate shutdown
shutdown /f /r - restart
